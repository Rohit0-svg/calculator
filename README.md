# Calculator

A menu-driven console calculator written in Python.

## Features
- Addition, subtraction, multiplication and division
- Handles invalid input and division by zero
- Runs in a loop until you choose Exit

## How to run
1. Install Python 3
2. Download `calculator.py`
3. Run `python calculator.py` in your terminal

## What I learned
Functions, conditionals, loops, input validation and exception handling.
